## FactorTheorem fallback answer-contract 修正

問題：

共用 fallback：

`_build_factor_theorem`
→ `root_to_factor`

曾把單一問題：

「已知 x=r 為根，求對應一次因式」

錯誤轉成 fake multi_part：

`part_1 = x-r`  
`part_2 = x-r`

而 canonical answer 為：
`x-r；可整除`

同時 generic convert 未提供：
`answer_contract.parts`

導致：
`multi_part_answer_checker`
在 `parts=[]` 時 `overall_correct` 永遠 False。

第一次錯誤批改後又進入 `STATUS_ANSWERED`，
造成再次提交顯示：
「此題已批改過。」

修正：

- `answer_type`：
  `multi_part` → `expression`
- canonical：
  `x-r`
- checker：
  `expression_checker`
- 題幹只保留單一數學任務：
  求對應一次因式
- 不再建立假的第二輸入框
- 真正 multi_part component 不受影響

`x=3`

正解：
`x-3`

`check_answer`：
`x-3` → PASS  
`(x-3)` → PASS  
`x+3` → FAIL
