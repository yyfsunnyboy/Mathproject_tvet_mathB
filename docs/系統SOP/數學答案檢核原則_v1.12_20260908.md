# 數學答案檢核原則（v1.12.2）

日期：2026-09-08（v1.12.2 增補：2026-11-22）

正式規格對應：`docs/系統SOP/Gencode_AgentSkillV3整合/SOP_Gencode_AgentSkillV3_Specification.md` §8.4

共用 checker 層為權威；不得另建平行 Checker。不處理 CartesianCoordinateSystem skill-local `check()`（仍 deferred）。

## 流程

所有數學答案類 checker 採：

```text
safe parse → normalize → mathematical equivalence → optional required-form validation
```

不得只做純文字比對。

## 規則

1. 數值依數學值比較，不做純文字比對。
2. 分數允許等價分數。
3. 代數式支援隱含乘法。
4. 方程式依等價性判斷。
5. multi_part 逐 part grading；**整題正確**＝所有 parts 皆正確（`overall_correct`）。部分小題正確不得提前計入 B1 題型 MASTERED。
6. single_choice 使用 semantic answer mapping。
7. text_short 只用於真正文字答案。
8. parse failure → `ANSWER_PARSE_FAILED`。
9. checker exception → `CHECKER_EXECUTION_FAILED`。
10. 因式分解等題型：先驗證代數等價，再驗證 required form。
11. **有序多值／具名賦值**（見下節）：僅在契約可判定時啟用；不得把有序答案當無序集合。

## 有序多值答案（ordered named values）

### 何時啟用

僅當下列之一成立時，共用 `expression_equivalence_checker` 才走有序多值路徑：

- canonical／`expected_answer` 為**具名賦值列表**（例：`a=0,b=3`），或
- `answer_contract`（或 multipart part）含 `variable_order`／`ordered_variable_names`，且 `answer_shape=ordered_named_values`（可由 adapter 自賦值 canonical 推得）。

不得對一般代數式、方程式、集合、區間任意以空白拆分。

### 變數順序

- 無標籤數值列表（`0,3`、`0 3`、`(0,3)`）依 **canonical／`variable_order` 的變數順序**解讀。
- 有標籤（`a=0,b=3`、`b=3,a=0`）依**變數名稱**對應，不依文字排列。
- 順序顛倒的無標籤輸入（`3,0` 對 `a=0,b=3`）必須 FAIL。
- 不得當成無序集合；與「`1 或 21`」類 unordered value-list 路徑分離。

### 可接受輸入（高職友善）

在啟用前提下，下列應 PASS（數值須數學等價）：

| 形式 | 例 |
| --- | --- |
| 半形／全形逗號 | `0,3`、`0，3` |
| 半形／全形空白 | `0 3`、`0　3` |
| 括號 | `(0,3)` |
| 具名賦值 | `a=0,b=3`、`a = 0, b = 3`、`a=0 b=3` |
| 負數／分數／小數 | `-2 5`、`1/2 -3/4`、`0.5 -1.25` |

必須 FAIL：數值不足／過多、未知變數標籤、空白、僅部分變數、無標籤順序顛倒、一般代數式被誤當多值。

### 實作與測試

- 實作：`core/checkers/expression_equivalence_checker.py`（`_assignment_lists_equivalent`／`ordered_variable_names_from_expected`）
- Multipart 分派：`core/checkers/multi_part_answer_checker.py`（各小題獨立；逗號／空白屬**單一 part 內容**，不得拆成兩個 multipart 欄位）
- 契約註記：`core/gencode/domain_matrix_adapter.py`（自賦值 expected 寫入 `variable_order`）
- 測試：`tests/test_ordered_named_values_checker.py`；既有 unordered／assignment 回歸見 `tests/test_b1_answer_equivalence_regression.py`

### Multipart 與掌握制

- `(1)` 有序多值 + `(2)` 多項式：僅兩 part 皆正確 → 整題正確 → 才可計入該 `problem_type_id` 的 MASTERED。
- 回饋須標出失敗的 part；不得因格式寬鬆而接受數學不等價答案。

## 代表案例

| canonical | 學生輸入 | 結果 |
| --- | --- | --- |
| `(x-1)(x-2)` | `(x-2)(x-1)` | PASS |
| `1/2` | `2/4` | PASS |
| `x=3` | `3=x`、`2x=6` | PASS |
| `(x-1)(x-2)` 且要求 factorized form | `x^2-3x+2` | FAIL required-form |
| `a=0,b=3` | `0,3`、`0 3`、`a=0,b=3` | PASS |
| `a=0,b=3` | `3,0`、`a=3,b=0` | FAIL |

說明：`x^2-3x+2` 即使與 `(x-1)(x-2)` 代數等價，若題目要求因式分解形式，仍 FAIL required-form。
