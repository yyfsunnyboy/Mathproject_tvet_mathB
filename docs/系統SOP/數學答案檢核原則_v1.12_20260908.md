# 數學答案檢核原則（v1.12.1）

日期：2026-09-08

正式規格對應：`docs/系統SOP/Gencode_AgentSkillV3整合/SOP_Gencode_AgentSkillV3_Specification.md` §8.4

本輪只收尾共用 checker 層。不修改 checker 行為、不處理 CartesianCoordinateSystem、不開始其他章節。

## 流程

所有數學答案類 checker 採：

```text
safe parse → normalize → mathematical equivalence → optional required-form validation
```

不得只做純文字比對。

## 規則

1. 數值依數學值比較，不做純文字比對。
2. 分數允許等價分數。
3. 代數式支援隱含乘法。
4. 方程式依等價性判斷。
5. multi_part 逐 part grading。
6. single_choice 使用 semantic answer mapping。
7. text_short 只用於真正文字答案。
8. parse failure → `ANSWER_PARSE_FAILED`。
9. checker exception → `CHECKER_EXECUTION_FAILED`。
10. 因式分解等題型：先驗證代數等價，再驗證 required form。

## 本輪代表案例

| canonical | 學生輸入 | 結果 |
| --- | --- | --- |
| `(x-1)(x-2)` | `(x-2)(x-1)` | PASS |
| `1/2` | `2/4` | PASS |
| `x=3` | `3=x`、`2x=6` | PASS |
| `(x-1)(x-2)` 且要求 factorized form | `x^2-3x+2` | FAIL required-form |

說明：`x^2-3x+2` 即使與 `(x-1)(x-2)` 代數等價，若題目要求因式分解形式，仍 FAIL required-form。
